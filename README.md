# Java Chess

A Java-based chess game originally developed in BlueJ as a high school programming project.

## About

This project implements the core structure of a chess game using object-oriented programming in Java. Individual chess pieces are represented by separate classes that inherit from a common `Chess_Piece` class.

The project includes:

- An 8x8 chess board
- Standard chess piece classes
- White and black player turns
- Piece movement logic
- Capturing
- Unicode chess piece display
- Object-oriented class structure

## Project Structure

- `Chess.java` - Main game loop
- `Board.java` - Chess board and board management
- `Chess_Piece.java` - Base class for chess pieces
- `Pawn.java`
- `Rook.java`
- `Knight.java`
- `Bishop.java`
- `Queen.java`
- `King.java`

## Project Status

This repository contains the original source code from the high school project. I am currently revisiting the project to improve the game logic, structure, and functionality using the programming concepts I have learned since originally developing it.
